1. OVERVIEW & SEO GOALS
================================================================================
Rank Pilot is an AI-powered SaaS that performs real-time technical website 
audits and tracks Google keyword rankings. The primary SEO objectives:

1. Rank for high-intent keywords: "AI SEO analyzer", "SERP rank tracker", 
   "Google keyword ranking tool", "free technical SEO audit", "Gemini SEO".
2. Establish a high CTR (Click-Through Rate) with rich social preview banners 
   (Open Graph / Twitter Cards) and Google FAQ rich snippets.
3. Keep user-generated reports and authentication screens strictly protected 
   from search engine indexing (Zero privacy leaks via Noindex).
4. Achieve 95+ Core Web Vitals score through preconnects, font swapping, 
   instant bundle delivery (<135 kB gzip), and HTTP caching.
5. Enable automated discovery by traditional search engines (Google, Bing) 
   and AI Answer Engines (Perplexity, ChatGPT, Claude).

[Step 2.4] Security Headers, HTTPS, and Caching Policy
-------------------------------------------------------
File: client/vercel.json (UPDATED)
Changes made:
- Added Strict-Transport-Security (HSTS):
  "max-age=63072000; includeSubDomains; preload"
- Added X-Frame-Options: "DENY" (Prevents Clickjacking)
- Added X-Content-Type-Options: "nosniff" (Prevents MIME-sniffing exploits)
- Added X-XSS-Protection: "1; mode=block"
- Added Referrer-Policy: "strict-origin-when-cross-origin"
- Added Permissions-Policy: "camera=(), microphone=(), geolocation=()"
- Added 1-Year Immutable Caching for production bundles:
  /assets/(.*) -> Cache-Control: "public, max-age=31536000, immutable"
- Added 24-Hour Caching for crawlers:
  (robots.txt|sitemap.xml|site.webmanifest|favicon.svg|og-image.svg)
- Configured clean SPA rewrites (source: "/(.*)", destination: "/").

[Step 2.5] Core Web Vitals (LCP, INP, CLS)
-------------------------------------------
- LCP (Largest Contentful Paint):
  - Preconnected to fonts.googleapis.com and fonts.gstatic.com in index.html.
  - Linked font stylesheet directly in HTML head, avoiding render-blocking 
    CSS `@import` overhead.
- CLS (Cumulative Layout Shift):
  - Fonts configured with `display=swap` to prevent invisible text flash.
  - Hero and sections have reserved min-height (`min-h-screen`) to prevent 
    layout jumps as data loads.
- Production Bundle Performance:
  - Total compressed size: ~134 kB gzip.
  - Total Vite build time: ~1.9s.

6. HOW TO VERIFY IN GOOGLE SEARCH CONSOLE
================================================================================
1. Go to https://search.google.com/search-console
2. Click "Add Property" -> Select "URL prefix" -> Enter:
   https://ai-seo-rank-tracker-seven.vercel.app/
3. Choose "HTML tag" verification method.
4. Copy your verification code, paste it into `client/index.html` replacing
   `YOUR_GOOGLE_SEARCH_CONSOLE_CODE`, and click "Verify".
5. In the left menu, click "Sitemaps" -> Submit:
   `https://ai-seo-rank-tracker-seven.vercel.app/sitemap.xml`
6. Google will immediately start discovering and indexing all your pages!
